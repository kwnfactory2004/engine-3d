# ENGINE 3D
エンジンの中の動きを、ブラウザで回して見られる勉強用3Dモデル集。

🔗 **公開URL**: https://kwnfactory2004.github.io/engine-3d/

## 収録
- `1jz-gte/` … トヨタ 1JZ-GTE（後期型・VVT-i・シングルターボ）。通常版とカットモデル版
- `13b-rew/` … マツダ 13B-REW（FD3S・2ローター・シーケンシャルツインターボ）
- `g16e-gts/` … トヨタ G16E-GTS（GRヤリス・1.6L 直列3気筒ターボ）。通常版とカットモデル版
- `g40e-v8/` … トヨタ GR GT の 4.0L V8 ツインターボ（通称 G40E・ホットV）。通常版とカットモデル版。発表直後のため推定が多い

## 機能
- 中の部品（クランク・ピストン・ローター・カム・バルブなど）が動く
- 再生／一時停止／少しずつ進める／はやさ、角度の表示
- 気筒（作動室）ごとの行程（吸入・圧縮・燃焼・排気）を色で表示
- 外側を透かす、部品グループの表示・非表示、クリックで部品名

## 使い方
1. 公開URLを開いて、エンジンを選ぶ
2. ドラッグで回す・ホイールで寄る・右ドラッグで動かす

## 技術
HTML / JavaScript（three.js を CDN から読み込み）。3Dモデル（glTF・Draco圧縮）は各HTMLの中に埋め込み。モデルは Blender + Python で作成。
