# ENGINE 3D
エンジンの中の動きを、ブラウザで回して見られる勉強用3Dモデル集。

🔗 **公開URL**: https://kwnfactory2004.github.io/engine-3d/

- `13b-rew/` … マツダ 13B-REW（FD3S・2ローター・シーケンシャルツインターボ）
- `g16e-gts/` … トヨタ G16E-GTS（GRヤリス・1.6L 直列3気筒ターボ）
- `g40e-v8/` … トヨタ GR GT の 4.0L V8 ツインターボ（通称 G40E・ホットV）。発表直後のため推定が多い
- `2jz-gte/` … トヨタ 2JZ-GTE（JZA80 前期・3.0L 直列6気筒ツインターボ）
- `rb26dett/` … 日産 RB26DETT（R34 スカイラインGT-R・2.6L 直列6気筒ツインターボ）
- `ej20/` … スバル EJ20（EJ207・WRX STI・2.0L 水平対向4気筒ターボ）。外まわりは写真からの推定を含む
- `sr20det/` … 日産 SR20DET（S15 シルビア・2.0L 直列4気筒ターボ）。S15の写真が無く、外まわりはS13/S14の写真からの推定を含む
- `fa20/` … スバル FA20D（トヨタ86／スバルBRZ 前期・2.0L 水平対向4気筒NA）。外まわりは写真からの推定を含む
- `vr38dett/` … 日産 VR38DETT（R35 GT-R・3.8L 60度V6ツインターボ）。ボアピッチなど一部は資料が無く推定
- `1lr-gue/` … レクサス 1LR-GUE（LFA・4.8L 72度V10）。点火順などは推定を含む
- `1gz-fe/` … トヨタ 1GZ-FE（センチュリー・5.0L 60度V12）。外まわりは写真からの推定を含む
- `1gd-ftv/` … トヨタ 1GD-FTV（ランクル・ハイラックス・2.8L 直列4気筒ディーゼルターボ）。ボアピッチなど一部は推定

## 機能
- 中の部品（クランク・ピストン・ローター・カム・バルブなど）が動く
- 再生/一時停止/少しずつ進める、角度の表示
- 回転数（rpm）を 1rpm〜実物の回転域（最大 7000〜8000rpm）まで指定可。アイドル・3000・6000・最大のボタン付き（最大値は目安）
- 気筒（作動室）ごとの行程（吸入・圧縮・燃焼・排気）を色で表示
- 外側を透かす、部品グループの表示・非表示、クリックで部品名
- 3D表示を全画面にできる（右下の「全画面」ボタン、または F キー。閉じるのは「閉じる」か Esc）

## 使い方
1. 公開URLを開いて、エンジンを選ぶ
2. ドラッグで回す・ホイールで寄る・右ドラッグで動かす

## 技術
HTML / JavaScript（three.js を CDN から読み込み）。3Dモデル（glTF・Draco圧縮）は各HTMLの中に埋め込み。モデルは Blender + Python で作成。

## 注意
主な寸法は公表値や資料をもとにしているが、外まわりの位置や形は推定を含む。メーカー公式のものではない、個人の勉強用の非公式モデル。
